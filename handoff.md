## 4. Инженерная философия (Ponytail Philosophy)
- **Minimalism & Lazy Coding:** Никакого over-engineering. Мы не используем тяжелые библиотеки (Zustand, Redux) для простых задач. Все построено на нативных хуках React.
- **Strict React 19:** Строгий запрет на использование `setState` внутри `useEffect` (каскадные обновления). Все зависимые состояния вычисляются "на лету" (derived state) или лениво инициализируются.
- **UI/UX:** Никакого визуального мусора. Tailwind CSS 4. Интерфейс должен быть промышленным, прагматичным и информативным.

## 5. Основная архитектура и ключевые модули
1. **Вычислительные движки (`src/lib/calculator/`)**:
   - `unifiedEngine.ts`: Движок расчетов SQLite WAL (WinCC Unified).
   - `comfortEngine.ts`: Движок расчетов CSV/RDB (Comfort Panels, макс 500,000 записей, лимит 32 ГБ).
   - `professionalEngine.ts`: Движок MS SQL (WinCC Professional, Fast/Slow Logging).
   - `networkEngine.ts`: Движок оценки пропускной способности Industrial Ethernet.
2. **Экспорт / Импорт**:
   - `src/lib/tiaExporter.ts`: Генерация `.xlsx` / `.csv` по строгим спецификациям TIA Portal.
   - `src/lib/tagImporter.ts`: Умный парсинг времени циклов и параметров из `.xlsx` и `.csv`.
3. **UI Компоненты**:
   - Основные вкладки панелей лежат в `src/components/tabs/`.
   - Модальные окна (отчет, шпаргалка, шаблоны, импорт) лежат в корне `src/components/`.
